## Image Guidelines

- **Format**: JPG or WebP preferred
- **Quality**: High quality, but optimized for web (use tools like TinyPNG)
- **File size**: Aim for under 500KB per image after optimization
- **Dimensions**: Match recommended sizes or use higher resolution
- **Naming**: Use exact filenames as listed above (case-sensitive)

## Optimization Tools

- [TinyPNG](https://tinypng.com/) - Online compression
- [ImageOptim](https://imageoptim.com/) - Mac app
- [Squoosh](https://squoosh.app/) - Online image optimizer

## Placeholder Images

For testing, you can use placeholder services:

- https://placehold.co/1920x1080
- https://picsum.photos/1920/1080

Example:

```bash
# Download placeholder images (requires curl)
curl https://picsum.photos/1920/1080 -o header-1.jpg
curl https://picsum.photos/1920/1080 -o header-2.jpg
curl https://picsum.photos/1920/1080 -o header-3.jpg
```
